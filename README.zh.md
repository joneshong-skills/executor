# executor

Read a blueprint and execute it phase by phase with discipline and deviation tracking.

## 說明

Executor reads a `.blueprint.md` file generated by the Blueprint skill and faithfully carries out each phase: tracking progress, verifying completion, logging any deviations, and producing a final report.

## 功能特色

- Reads and parses `.blueprint.md` files from the Blueprint skill
- Executes implementation phase by phase in dependency order
- Tracks progress and marks phases complete after verification
- Logs any deviations from the original plan with reasons
- Produces a structured completion report at the end
- Stops and flags when a phase cannot be completed as specified

## 使用方式

透過以下觸發語句呼叫 Claude Code 來使用此技能：

- "execute the blueprint"
- "run the plan"
- "follow the blueprint"
- "按照藍圖執行"
- "執行 blueprint"

## 安裝

將技能目錄複製到 Claude Code 技能資料夾：

```
cp -r executor ~/.claude/skills/
```

放置在 `~/.claude/skills/` 的技能會被 Claude Code 自動發現，無需額外註冊。
